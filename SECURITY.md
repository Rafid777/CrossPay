# Security Policy

## Supported Versions

| Version | Supported | Status |
| :--- | :--- | :--- |
| 2.1.x | :white_check_mark: | Active Enterprise Production |
| 2.0.x | :white_check_mark: | Security Patches Only |
| < 2.0 | :x: | End of Life |

## Reporting a Vulnerability

CrossPay takes security and financial integrity seriously. If you discover a potential vulnerability, please report it privately:

1. **Do NOT open a public GitHub issue.**
2. Send an email to the security response team with subject line `[SECURITY] CrossPay Vulnerability Report`.
3. Include detailed steps to reproduce, affected files, and potential impact.

## Vulnerability Handling SLA

- **Acknowledgment:** Within 24 hours.
- **Triage & Assessment:** Within 48 hours.
- **Patch Release:** Critical vulnerabilities are patched within 7 days.

For more details on CrossPay's 3-tier security model and threat evaluation, consult [`docs/security-assessment.md`](docs/security-assessment.md).
